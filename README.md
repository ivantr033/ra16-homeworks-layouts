# Домашнее задание к блоку «События и состояние» — Задача «Расположение товаров»

Веб-приложение для интернет-магазина, реализующее динамическое переключение раскладки каталога товаров (сетка / вертикальный список) и условный рендеринг компонентов.

## 🚀 Функциональность и архитектура

Приложение построено на базе строгого компонентного подхода React с разделением ответственности и однонаправленным потоком данных (Unidirectional Data Flow):

- **`Store` (Классовый компонент):** Главный управляющий компонент приложения. Хранит внутреннее состояние текущего вида отображения (`this.state.view`) со значениями `'view_module'` или `'view_list'`. Отвечает за логику переключения и условный рендеринг макетов.
- **`IconSwitch` (Функциональный компонент):** Безликий (stateless) компонент для отображения иконки-переключателя. Принимает имя иконки и функцию обратного вызова (`onSwitch`) через пропсы, возвращая событие клика родителю.
- **`CardsView` & `ListView` (Функциональные компоненты):** Отвечают за организацию структуры отображения товаров в виде сетки (Grid) или списка (Flexbox) соответственно.
- **`ShopCard` & `ShopItem` (Функциональные компоненты):** Чистые компоненты отрисовки атомарных карточек и строк товаров.

## 🎨 Оптимизация медиа-контента с помощью CSS

Для устранения избыточных пустых полей в оригинальных изображениях обуви и достижения точного соответствия макету Netology, были применены современные техники CSS-маскирования:

- Использование `overflow: hidden` на контейнерах-обертках картинок (`card-image-wrapper` и `item-image-wrapper`).
- Динамическое масштабирование через `transform: scale()` для автоматического кадрирования и отсечения невидимого воздуха по краям.
- Свойство `object-fit: contain` для сохранения пропорций изделий без деформаций при адаптивном сжатии.

## 🛠️ Технологический стек

- **Frontend:** React 19, JSX
- **Сборщик:** Vite 8
- **Иконки:** Material Icons CLI (Google Fonts)
- **CI/CD:** GitHub Actions (автоматический сборщик пакета `dist` и деплой на ветку `gh-pages`).

## 🔧 Локальное развертывание

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите сервер для разработки:

   ```bash
   npm run dev
   ```

3. Откройте локальный адрес в браузере: `http://localhost:5173`
